# Living Heirloom

A 1921 Albanian Commemorative Medal certificate (Албанска споменица), brought back to life:
a restoration pipeline straightens and color-corrects the scan without inventing detail, and a
deep-zoom website explains every seal, signature and line of text.

```
source/      original photo / scan (placeholder.jpeg until the real scan arrives)
pipeline/    Python: straighten, color-correct, export master + Deep Zoom tiles
site/        TypeScript + Vite + OpenSeadragon static website
```

## Requirements

- [uv](https://docs.astral.sh/uv/) (Python 3.12 is installed by uv if missing).
  libvips comes bundled through the `pyvips[binary]` wheel; no system install needed.
- Node.js 22+ and [pnpm](https://pnpm.io/) 10

## Setup

```sh
(cd pipeline && uv sync)
(cd site && pnpm install)
uv run --directory pipeline pre-commit install   # git hooks: format, lint, type check
```

## Run

```sh
# 1. Build the image + tiles (writes pipeline/output/ and site/public/tiles/)
uv run --directory pipeline spomenica-pipeline
#    with the real scan:
uv run --directory pipeline spomenica-pipeline --source ../source/scan.tif --rotate 0

#    the placeholder photo has no visible paper edges, so crop it by hand (normalized
#    x,y of top-left, top-right, bottom-right, bottom-left, after rotation):
uv run --directory pipeline spomenica-pipeline --corners 0.01,0,0.95,0.01,0.94,1,0,0.99

# 2. Website
cd site
pnpm dev        # local dev server
pnpm build      # static site in site/dist/ (GitHub Pages / Netlify)
```

## How the pipeline works

All analysis runs on a ~1600 px proxy (OpenCV); the full-resolution image is only touched by
lazy libvips operations, streamed tile by tile, so multi-gigapixel scans need little RAM
(a 192-megapixel test input peaked at ~500 MB).

1. **Rotate** to upright (`--rotate`, default 90° clockwise for the placeholder photo).
2. **Find the document**: manual `--corners`, or automatic detection of the largest
   quadrilateral (paper lighter or darker than its background). If no convincing edge is
   found, the whole frame is kept and a warning is printed.
3. **Correct perspective** with a homography (libvips `mapim`).
4. **Flat-field against the paper**: in a 40-cell grid the brightest 10% of pixels per cell
   are taken as bare paper; that smooth "paper field" (color cast + vignette + broad glare)
   is divided out, ink is stretched to black, and clean paper is mapped to an aged-paper tone.
   No detail is invented: it is a per-pixel tone mapping only.
5. **Export** `pipeline/output/master.tif` (tiled, lossless), `preview.jpg`, and Deep Zoom
   tiles (WebP by default; `tile_format = "jpg"` in config for JPEG) in
   `site/public/tiles/spomenica.dzi`.

Tuning knobs (grid size, gain cap, paper tone, tile size, ...) are in
`pipeline/src/spomenica_pipeline/config.py`.

## The website

```
site/
  public/points.json         pins: id, title, body, region, optional pin position
  public/transcription.json  transcription lines with regions and modern explanations
  public/tiles/              generated by the pipeline
  src/
    data/           zod schema (validated at load time) + loading
    viewer/         OpenSeadragon facade, coordinate conversion, keyboard mapping
    pins/           numbered pins + region highlights (OpenSeadragon overlays)
    panel/          side panel (desktop) / bottom sheet (phone) and its views
    tour/           tour order (top to bottom) and previous/next logic
    i18n/           UI strings, Cyrillic → Latin transliteration
    state/          tiny observable store, URL-hash deep links
    ui/             toolbar, DOM helpers
    dev/            dev mode for placing pins
  tests/unit/       Vitest: pure logic + validation of the shipped JSON
  tests/e2e/        Playwright (desktop + phone): behavior, axe accessibility audit
```

**Features:** full-screen viewer; numbered pins (constant screen size, 44×44 px targets) with
region highlight on hover/focus/select; contents list; guided tour (top to bottom) with
previous/next; transcription panel where each line zooms to its place; "Цео документ"
(whole document) button; minimap on desktop; draggable bottom sheet on phones; deep links
(`#pecat`, `#ukaz`, …); hide-pins toggle; Cyrillic/Latin toggle (remembered); light/dark
mode; keyboard (arrows pan, `+`/`-` zoom, `0` whole document, Tab through pins, Esc closes
the panel); `prefers-reduced-motion` jumps instead of flying; iPhone safe areas.

### Editing content

- All coordinates are **normalized 0–1** relative to the image, so they survive re-running the
  pipeline on the real scan (as long as the crop is the document edge both times).
- Serbian text is written **in Cyrillic only**; the Latin version is generated. Every text is
  `{ "sr": "…" }`, ready for an `"en"` translation later.
- `verify` lists hold notes about facts that still need checking. They are shown only in
  dev mode.
- Invalid data never renders half a page: the schema check reports `path: problem` in the
  browser console and an error message on screen. `pnpm test` validates both files too.

### Dev mode: placing pins

Open `http://localhost:5173/?dev`. Pick a point or transcription line in the DEV box, then:

- **click = pin**: one click on the document moves the pin there;
- **click ×2 = region**: click two opposite corners.

The cursor position (normalized) is shown live. Press **Copy JSON** and paste it over
`public/points.json` (or `transcription.json` when a line is selected).

### Deploying

`pnpm build` produces a fully static `site/dist/` with relative paths, so it works from any
sub-path. `.github/workflows/pages.yml` deploys it to GitHub Pages on every push to `main`
(enable once: Settings → Pages → Source: GitHub Actions). For Netlify: base directory
`site`, build command `pnpm build`, publish directory `site/dist`.
